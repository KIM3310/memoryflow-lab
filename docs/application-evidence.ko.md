# 2026 SK hynix 지원서 근거 초안

## 지원 직무

1순위: Software Solution - 플랫폼 소프트웨어 연구

## 반도체 직무 전문성

AI 반도체 아키텍처 설계 및 성능 최적화 과정을 수료한 뒤, LLM 추론의 메모리 병목을 직접 검증하는 MemoryFlow Lab을 구현했습니다. 모델 구조에서 GQA의 KV cache 크기를 계산하고, 가중치가 차지한 뒤의 HBM 잔여 용량을 기준으로 배치 가능성을 먼저 판정했습니다. 이후 HBM-only, hot-window 기반 원격 메모리 tiering, near-memory proxy를 동일 워크로드에서 비교해 용량·지연·처리량·데이터 이동·에너지 proxy를 토큰별로 추적했습니다. 실험 결과를 일반화하지 않고, 원격 대역폭·overlap·정밀도·문맥 길이에 따라 결론이 바뀌는 조건과 실측 보정 계획까지 명시했습니다.

## AI 활용 역량

AI 코딩 도구를 설계 초안, 구현, 테스트 후보 생성, 문서 교정에 활용했습니다. 다만 수치 결론은 LLM이 생성하지 못하도록 deterministic core로 분리했습니다. 제가 직접 문제를 KV placement로 한정하고, 식·단위·capacity gate·가설별 반례·90% coverage 기준·재현 가능한 evidence hash를 정의했습니다. AI 출력은 `make verify`를 통과하고 가정을 설명할 수 있을 때만 채택했습니다. 이를 통해 AI를 결과 대행 도구가 아니라 탐색 속도를 높이고 검증 범위를 넓히는 도구로 사용했습니다.

## 면접에서 보여줄 증거

- 한 줄 변경으로 원격 대역폭을 바꾸고 결론 재생성
- GQA와 MHA의 KV 용량 차이 계산
- HBM-only 탈락 이유를 단위와 수치로 설명
- near-memory 가정의 약점과 추가 검증 실험 제안
- 실패하는 테스트를 먼저 보여준 뒤 수정 과정 설명
